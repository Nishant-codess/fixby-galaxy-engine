## 1. Executive Summary & Philosophy

In hackathons, teams fail to integrate when they work in silos without strict interface boundaries, merge late on the final day, or hide their complex backend logic inside terminal logs that judges never see.

**Our Core Principles:**
1. **Contract-First Independence:** Interface models (`contracts/schema.py`) and realistic sample data (`contracts/mock_responses.json`) are locked on **Day 1**. Every member can build and test their system independently without waiting for any teammate.
2. **Zero-Conflict Monorepo Architecture:** Each team member owns a strictly segregated directory. Nobody edits another member's files without a pull request.
3. **Dual-Pillar Innovation:** We combine rock-solid production engineering with 3 domain algorithms AND **5 visually stunning UI innovations** that make the engine's intelligence immediately tangible to judges.
4. **End-to-End Ownership (Build + Test):** Each member is responsible for the complete lifecycle of their domain: implementation, mock unit testing, integration verification, and documentation.

### The 5 Visible Innovations (What the Judges Actually Experience)

#### 🌟 Visible Innovation 1: Live One UI Settings Simulator
* **What it is:** When a troubleshooting step is selected (e.g., *"Put unused apps to sleep"*), the 3D Galaxy phone screen animates through simulated One UI settings:
  * Screen slides from Home $\rightarrow$ Settings $\rightarrow$ Battery $\rightarrow$ Background Usage Limits.
  * A glowing touch-ripple highlights the exact toggle button.
* **Why it wins:** Judges instantly see *how* the customer is guided, turning abstract JSON into an intuitive visual demo.

#### 🌟 Visible Innovation 2: Interactive Diagnostic Decision Graph (DAG Flowchart)
* **What it is:** An interactive, pan-and-zoom node graph alongside the phone displaying the dynamic troubleshooting DAG generated by our engine.
* **Visual States:**
  * 🟢 **Safe / Non-destructive** (Clear Cache, Optimize Battery).
  * 🟡 **Caution** (Reset Network Settings, Boot in Safe Mode).
  * 🔴 **Critical** (Factory Data Reset).
* **Interactivity:** If the user clicks *"Problem not fixed"*, the active path visually branches to the next contingency node with a glowing animation.

#### 🌟 Visible Innovation 3: Real-Time Engine "X-Ray / Judge HUD"
* **What it is:** A collapsible slide-out drawer designed specifically for hackathon evaluation:
  * **Language Telemetry:** Shows raw Hinglish input transformed into canonical intent (`mera phone hang ho raha hai` $\rightarrow$ `performance.general_lag`).
  * **Latency Speedometer:** Visual needle showing response tier (⚡ 14ms Tier-1 Hash, 🧠 180ms Tier-2 Semantic, ⏱️ 1.2s Cold Generation).
  * **Taxonomy Heatmap:** Visual subsystem meters (Battery: 85%, Performance: 90%).
  * **Grounding Badge:** Displays exact source excerpt (`siis_responses.json#42`) with 100% citation confidence.

#### 🌟 Visible Innovation 4: Instant Real-Device QR Bridge
* **What it is:** Every automated step displays an expandable "Test on your Galaxy" QR code.
* **Functionality:** Scanning the QR code with an actual Galaxy phone opens the native URI scheme (`bixby://settings/...` or Android settings intent).
* **Impact:** Demonstrates that the engine directly integrates with real Samsung hardware.

#### 🌟 Visible Innovation 5: Bilingual Voice Assistant with Dynamic Orb
* **What it is:** Hands-free voice troubleshooting supporting English and Hindi/Hinglish.
* **Features:**
  * Animated pulsing voice orb (mimicking One UI Bixby styling).
  * Dynamic soundwave visualizer responding to voice input.
  * Natural text-to-speech audio feedback reading out the diagnostic instructions.

## 4. Git Branching & Merging Strategy

### Branches:
* `main`: Production-ready, stable codebase. Tagged `PRISM_GENAI_HACKATHON_Y2026` at submission.
* `develop`: Integration branch where feature branches meet.
* `feat/lead-core-pipeline`: Member 1 working branch.
* `feat/aiml-engine`: Member 2 working branch.
* `feat/frontend-galaxy-ui`: Member 3 working branch.
* `feat/backend-fastapi`: Member 4 working branch.

### The 4 Sync Milestones:

```
Day 1: CONTRACT FREEZE
       contracts/schema.py and contracts/mock_responses.json committed to develop.
       All 4 members branch off develop.
       
Day 2: INDEPENDENT COMPONENT BUILDS
       Members build & run tests against local mock fixtures.
       No blocking dependencies.

Day 3: MID-WAY INTEGRATION CHECKPOINT
       Member 4 connects FastAPI routes to Member 1's pipeline.py.
       Member 3 connects fetch('/v1/troubleshoot') to Member 4's server.
       PRs merged into develop. First live end-to-end test!

Day 4: DIFFERENTIATOR & POLISH SPRINT
       Member 2 integrates Diagnostic Graph Generator.
       Member 3 integrates Three.js 3D model & HUD Inspector.
       Member 1 connects Symptom Taxonomy & Scorer.

Day 5: CODE FREEZE & BENCHMARKING
       develop merged into main.
       Full benchmark run generating metrics.md & results.jsonl.
       docker compose up validated on clean machine.
       Git tag created: PRISM_GENAI_HACKATHON_Y2026.
```
